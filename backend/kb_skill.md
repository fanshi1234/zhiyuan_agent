# 志愿Agent — 知识库调用指南

> **目标**：指导 Agent 按业务语义分类调用 `kb/` 知识库，确保回答高考志愿相关问题时精准、高效、避免无关内容。

---

## 二、调用规则（核心）

### 2.1 问题类型 → 知识库目录映射

| 用户问题类型 | 优先检索目录 | 示例问题 |
|-------------|-------------|---------|

| **风格类** | `05_张雪峰风格库/` | "怎么用张雪峰的风格回答？" "张雪峰风格FAQ" |

### 2.2 调用优先级

```
1. 核心业务目录（01-08）> 2. 全局导航文件 > 3. 其他目录
```

- **核心业务目录**：`01_政策规则/`, `02_省份数据/`, `03_院校库/`, `04_专业库/`, `05_张雪峰风格库/`, `06_案例库/`, `07_录取数据/`, `08_提示词模板/`
- **全局导航文件**：`00_全国高考地图.md`, `00_文档关系图谱.md`
- **其他目录**：`00_项目总控/`, `09_产品设计/`, `10_AI补全规范/`, `11_发布导出/`

### 2.3 严禁混入的目录

以下目录 **不用于回答用户问题**，仅在内部开发/维护时使用：

- `_模板/`
- `scratch/`
- `12_skills/`

## 三、调用示例

### 示例1：政策类问题
```
用户问题："四川高考怎么选科？"

调用路径：
1. kb_search("四川 选科") → 优先匹配 `01_政策规则/四川_2026_普通高考政策框架.md`
2. kb_search("选科要求") → 优先匹配 `01_政策规则/全国_选科要求总览.md`
3. kb_search("四川 高考 政策") → 优先匹配 `01_政策规则/四川_2026_普通高考政策框架.md`

回答策略：
- 引用政策文件原文
- 补充说明政策适用年份
- 如需案例，补充检索 `06_案例库/`
```

### 示例2：院校类问题
```
用户问题："电子科技大学有哪些优势专业？"

调用路径：
1. kb_search("电子科技大学") → 优先匹配 `03_院校库/四川/电子科技大学.md`
2. kb_search("电子科技大学 优势专业") → 优先匹配 `03_院校库/四川/电子科技大学.md` + `04_专业库/计算机类.md`
3. kb_search("电子科技大学 录取") → 优先匹配 `07_录取数据/电子科技大学.md`

回答策略：
- 列出院校基本信息
- 列出优势专业（结合专业库）
- 提供近年录取数据参考
```

### 示例3：综合类问题
```
用户问题："四川物理类600分能报什么学校？"

调用路径：
1. kb_search("四川 物理类 600分") → 优先匹配 `02_省份数据/四川/四川_录取数据总览.md`
2. kb_search("物理类 600分 院校") → 优先匹配 `03_院校库/` + `07_录取数据/`
3. kb_search("冲稳保 四川") → 优先匹配 `06_案例库/` + `08_提示词模板/`

回答策略：
- 先用数据库查询 `search_admissions(province="四川", score=600)`
- 再用知识库补充政策说明
- 最后用案例库提供填报建议
```

## 四、最佳实践

1. **精准关键词提取**：从用户问题中提取省份、分数、位次、选科、专业、院校等关键词
2. **多维度检索**：复杂问题需检索多个目录，综合回答
3. **数据优先**：录取数据优先查询SQLite数据库，知识库作为补充
4. **免责声明**：涉及具体学校/专业推荐时，引用 `08_提示词模板/免责声明模板.md`
5. **风格一致性**：回答风格参考 `05_张雪峰风格库/`，确保语言通俗易懂

```javascript

    return fetch(`/kb_search?q=${encodeURIComponent(query)}`)

        .then(data => data.results);
```

## 六、维护指南

1. **新增内容**：按业务语义放入对应目录
2. **更新内容**：标记 `updated:` 日期，确保版本一致
3. **删除内容**：标记为 `待补`，而非直接删除

## 七、常见问题

**Q：如何判断问题类型？**
A：提取关键词 → 匹配目录映射表 → 优先检索对应目录

**Q：知识库搜索不到怎么办？**
A：
1. 检查关键词是否准确
2. 尝试更宽泛的关键词
3. 检索全局导航文件 `00_全国高考地图.md`
4. 联网搜索补充（Tavily API）

**Q：多个目录都匹配怎么办？**
A：按优先级排序，核心业务目录优先，同一优先级按相关性排序
